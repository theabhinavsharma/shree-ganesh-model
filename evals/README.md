# Evals

`registry.yaml` is the spec: each eval in plain English (what must be true, why, source of truth, threshold, action,
owner). `src/agentic/eval_checks.py` measures each one; `src/agentic/run_evals.py` runs them and writes
`reports/eval_report_<date>.md` with the statement next to the result.

Human evals (owner: abhinav) stay PENDING until a person does them:
- `golden/order_book_to_grade.csv` — grade 50 filings (human_verdict: correct / wrong_amount / segment_only /
  not_a_backlog; human_total_book_cr). Generated by `src/agentic/make_golden_set.py`.
- `human_review/` — copy `TEMPLATE.md` to `<track>_<screen_id>.md` for each weekly batch, tick every box, sign.
  Real money stays blocked until the latest batch of each track is signed.
